## Structural arms

[kernel.py](kernel.py) builds two independent128-thread FP8 attention
warpgroups in each256-thread CTA. Each owns disjoint KV keys and all64 query
rows, so there is no query-partition KV reread. Named128-thread barriers
keep their copy/math progress independent. CTAs in a2/4-member cluster merge
their4/8 logical slices through DSM and apply norm/gate in the same launch.
All2055 union keys (2047 history plus8 appended tokens) are covered, with
per-query causal/window masks. BF16 and strided FP32 projection inputs retain
the required activation rounding; Q and P use FP8 E4M3, PV accumulates FP32.

- **STREAM2/STREAM4:** double-buffer historical KV copies while computing;
  prepare Q after PDL, then prepare new K/V only once in its owning logical
  slice after history drains. KN/VN reuse dead history buffers. Two-WG shared
  allocation is94208B; native172 registers, no stack/spills. This removes four
  launches, global split output/combine, duplicate new-KV preparation and the
  resident-history requirement.
- **WG2C2/WG2C4:** resident controls,512/256 keys per WG; history gather and
  transpose finish before its PDL wait. Shared153600/88064B;233 registers,
  no stack/spills. They distinguish whole-history residency from streaming.
- **RAW2:** identical streaming C2 source with the ordinary producer edge;
  STREAM2 uses the documented launch-completion programmatic edge for our
  consumer node. No producer or existing graph node is modified.
- **F8:** exact FA3 with num_splits8 only at v32; unchanged-A control at v16.

This is a hypothesis for approaching the target, not a measured1.3x result.
The current QKV producer needs196672/221508B shared at v16/v32. These
attention CTAs cannot co-reside with it on the same SM; spare SMs and producer
tails may permit prefetch. Neither an early kernel start nor prewait SASS
proves broad overlap. The packet records hardware phase clocks and critical
increments so a failed recipe does not falsely close early-history attention.
If the remaining limit is bulk prefetch admission, a smaller shared footprint
(for example register Q with compact K/V tiles) or a different producer is
still needed; that structure is not claimed implemented here.
