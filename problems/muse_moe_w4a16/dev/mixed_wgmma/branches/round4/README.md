# P3b warp-specialized heavy branch: measured loss

Payload **80c5d1c8**, CUDA **a43783e7**, generated by `build.py`. Controls S14 and CTA2;
WS_TILE_BARRIER andWS_PIPE differ in whether the next tile's stream can precede the previous
epilogue. TMA fills a two-slot raw-weight ring, three warps decode BF16 fragments, and two
RS-WGMMA consumers share X. Per-warp W2 norm partials feed the F4 finalizer. One CTA may
process another channel tile without returning to the host. NT1 and N16G4 are unchanged.

This differs from `8ee003db` by using CTA-local rings without multicast/cluster ownership;
from `ea794250` by leaving the light kernels and dependency graph intact; from `9cd95e72`
by using register-A consumers instead of SS decoded-A publication. These differences did
not yield a native gain. The exact recipe is closed; warp specialization as a family is open.

## Verified implementation and limits

Two forced local_eval adapters pass5 official +5 static checks. `validation.json` records1036
captured/poisoned/shifted checks,128 input cases, sizes33/127/128/255/256/257 and12 local_start64
checks. Worst L2/row .004212/.004782; barrier/PIPE outputs bit-equal to each other128/128.
24-seed weights=None entry with a1GiB cold-read callback passes locally; cached local timing
and sm120's smaller ring stand-in are not Hopper evidence.

Native `resources.json`: all eight specializations168 entry registers,1024 static bytes,
116736/149504/182272/215040 dynamic smem, zero spills/local-memory instructions, **one CTA/SM**
confirmed by the receipt. WG0 has88 registers; consumers208 each, total64512. CFG audit
shows WG0 physical maxR49 (MAX256) orR41, and no producer path reaches consumer allocation.
The confirmed register footprint prevents same-SM NT1 co-residency, though spatial overlap
across SMs remains possible. `protocol.json` records442 completion/progress tests including
a two-arrival empty barrier, S1/S2 negative overwrite/deadlock witnesses and200 modeled PIPE
cross-tile stream schedules. Unlike CTA2, both consumers retire before a shared slot is reused.
`packet.json` proves byte-permutation inversion; native math gates passed.

No P4 nomination. Follow-up [round6](../round6/README.md) removes the separate decoder and
BF16 publication, bounds token width for real two-CTA admission, and repairs the other
experiments instead of treating their unproven timings as losses. Native timing is still needed.
