## Ranked take

1. **Measure Humming W4A16 on the real H200 bank.** vLLM's current Humming path selects indexed or grouped-contiguous expert GEMMs under EP, defers activation processing when the input is BF16, and has a W4A16 route (`vllm/model_executor/layers/fused_moe/experts/fused_humming_moe.py`, commit `e4db46c79bca354fef07197465faea14ca563c09`; `vllm/model_executor/layers/quantization/moe_wna16.py`). The H200 probe is queued as `prof/lab/humming_nvfp4_probe.py`; no receipt has landed yet.
2. **Keep the existing V9 producer and prioritize the finalize/collective boundary.** vLLM's `fused_finalize.py` fuses per-route RMSNorm, router weighting, remote-route masking and top-k reduction in one Triton program. That is the same boundary where our V9 path still pays substantial work. Port or measure only the exact finalize schedule; do not replace the already faster V9 producer based on a library claim.
3. **Use runNburn's device-resident sequencing as a design reference.** Its CUDA Muse path keeps hidden/KV state on device, overlaps Q/K/V work, and chains attention through the dense tail, but it is Muse Glimmer (dense, Q4_K/Q6_K, head dimension 128), not Muse Spark (NVFP4 W4A16, MoE, head dimension 64). The reported RTX 3090 wins are useful mechanisms, not H200 evidence.
4. **Correct the serving model's DFlash rate to 4.05 tokens/verify step.** InferenceX's key 7 is the exact eight-wide serving flag (current token plus seven drafts), so 4.05 replaces the old 4.16 assumption. The scratch receipt composition changes from 1.807103x capped / 1.819826x extrapolated to **1.812741x capped / 1.825689x extrapolated**.
5. **Do not port GPU MODE's NVFP4 winners to H200.** The public winners use Blackwell `tcgen05`/TMA block-scaled MMA. They are useful for scale/layout reasoning, but Hopper cannot execute those instructions and the challenge requires BF16 activations.
6. **Do not use public GB200/GB300 throughput as an H200 claim.** Dynamo reports useful deployment flags and operating points, but its tables are another GPU and workload. The challenge's fixed TP8/EP8 + DFlash path still needs H200 receipts.
